# Middle Class Machan — Comedy Scripts (review)

**Format (ellaa joke-um):**
- Exactly **5 lines**.
- **Person 1** start pannuvaar (line 1), line 3, kadaisi line 5 — Person 1 dhaan end pannuvaar.
- **Person 2** line 2, line 4 — normal-ah kelvi kekkuravar.
- Line 5 = Person 1 lusu maadhiri solra punch 😂 → adhukku apram 🥁 ba-dum-tss + laugh clip.
- Ovvoru character-kum thani voice.

Maathanum-na joke number-oda sollunga (e.g. "F7 maathu", "A12 remove").

### F1. Charge eravae illa 🔌
1. **Machan:** மச்சான், என் phone-ல charge ஏறவே இல்ல டா!

5. **Machan:** Phone-ஐயும் charger-ல connect பண்ணணுமா டா? 😂
